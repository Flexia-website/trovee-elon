GOOGLE SITE VERIFICATION FILE

To verify your site with Google Search Console, follow these steps:

1. Go to: https://search.google.com/search-console
2. Click "Add Property"
3. Enter your domain name
4. Choose verification method: "HTML file upload"
5. Download the verification file from Google
6. Replace the contents of this file with Google's verification code
7. Upload this file to your server root directory
8. Google will verify your ownership

After verification:
- Submit your sitemap at: https://www.google.com/search-console
- Go to: Sitemaps section
- Submit:
  * /sitemap.xml
  * /sitemap-images.xml
- Monitor indexing progress
- Check coverage reports for any errors

ALTERNATIVE VERIFICATION METHOD (DNS):
If you can't upload files, use DNS verification:
1. Add the provided DNS TXT record to your domain's DNS settings
2. Wait for DNS propagation (can take up to 48 hours)
3. Google will verify automatically

TIPS:
- Verify both www and non-www versions
- Submit image sitemap for Google Images indexing
- Check "Coverage" report weekly
- Monitor "Performance" for keyword rankings
- Setup mobile-friendly testing in Search Console
